# Navigator + Omarchy Boundary

Status: PRODUCTION ARCHITECTURE

Builder Commons remains the AGENTROPOLIS workplace where humans and agents build together. Navigator and Omarchy extend that workplace without becoming its foundation.

## Placement

```text
AGENTROPOLIS
  -> Mission Control
    -> Navigator
      -> Builder Commons
        -> Project Rooms / Forge / Agent Dock / Compute Dock
          -> Hermes
            -> AGENT-MCP
              -> HERDR
                -> approved machine profile
                  -> Omarchy or another compatible host
```

## Ownership rules

- **Navigator** owns spatial/context presentation and address resolution.
- **Builder Commons** owns project/workspace collaboration state.
- **Hermes** coordinates missions and agents.
- **AGENT-MCP** exposes governed capabilities.
- **HERDR** owns machine registration, lifecycle, routing, health, metering and machine-scoped receipts.
- **Omarchy** is a preferred sovereign Linux workstation/launcher surface. It does not grant authority.
- **AEGIS / 54T** gate and verify consequential actions.
- **GitHub Pages / Cloudflare** are hosting targets, not architecture owners.

## Spatial mapping

```text
AGENTROPOLIS
  -> Builder Commons District
    -> Builder Atrium
    -> Forge
    -> Project Rooms
    -> Agent Dock
    -> Compute Dock
    -> Broadcast Tower
    -> XR Portal
    -> Opportunity Exchange
```

Every spatial operation must retain a non-spatial web, CLI, API or agent equivalent.

## Provider sovereignty

Builder Commons core must not require Base44, Lovable, Vercel or any hosted builder platform. Provider-specific services remain replaceable adapters. Source and portable contracts remain in Git.

## Authority invariant

Presence, navigation, workstation login, connected agents, successful builds and completed processes are descriptive evidence only. None independently grant deployment, wallet, production or economic authority.

Canonical action corridor:

```text
Identity
 -> Mandate
 -> Policy
 -> Capability Grant
 -> Execution Envelope
 -> Execution
 -> Verification
 -> Receipt
 -> Audit
```
