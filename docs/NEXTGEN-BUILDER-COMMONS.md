# Next-generation Builder Commons — resource intelligence and living construction

## Ownership
Builder Commons owns the collaborative project-room experience and resource-discovery catalog. CONSTRUCTION owns build orchestration, CREATOR-CORE owns media creation, Hermes owns agent runtime interoperability, ENTITY54 owns identity/capabilities, MATH54 owns quantitative benchmarking, 54-T owns enforcement, and CBE owns contributor matching. Do not collapse boundaries or invent production integration.

## First implementation
The pure resource intelligence module at `packages/resource-intelligence/index.mjs` validates resource evidence and blocks automatic approval when license, provenance, security review, or reproducible benchmark evidence is missing. It does not fetch URLs, run code, install packages, or grant authority. URLs are untrusted input. A production fetcher must additionally resolve DNS, block private/metadata ranges, validate each redirect, limit response sizes, and use isolated network egress.

## Spatial world
A navigable city with enterable workshops, persistent rooms, and high-fidelity Hermes worker avatars; red/cyan/obsidian Agentropolis DS. Render only authenticated job telemetry. Show idle, assigned, running, blocked, review, complete, and failed states. Do not fabricate agent work. Accessible 2D, mobile, CLI and reduced-motion alternatives remain mandatory. Keep rendering decoupled from the build engine.

## Construction corridor
Intent -> structured spec -> task graph -> capability/permission checks -> isolated build -> deterministic tests -> human approval for consequential actions -> artifact attestation -> receipt -> publish. Agents cannot self-approve or bypass protected branches. Sandbox shell, package installation, repository writes, secrets, browser, and network independently.

## Acceptance gates
1. Real authenticated project room persists and reloads.
2. At least one real repository connects via scoped token broker.
3. Real build job executes in a disposable isolated worker.
4. A failed test produces a visible failure and blocks shipping.
5. Each agent action is mapped to telemetry, not animation fiction.
6. Every consequential operation has an immutable, off-host-verifiable receipt.
7. 3D world remains usable on mobile with quality tiers and accessible fallback.
8. No auto-install from resource discovery; missing evidence remains UNKNOWN.
